Setup Guide

Up and running in
four steps

01

Install a Sideloader

Download and install Sideloadly or PlumeImpactor — this is used to install the Fortnite IPA onto your Mac.

02

Download FnMacAssistant

Grab the latest release from GitHub. Grant Terminal Full Disk Access in System Settings → Privacy & Security for full functionality.

03

Download & Install IPA

Use the IPA Downloads tab to fetch the latest Fortnite IPA, then install it via your sideloader using your Apple ID.

04

Patch & Play

Hit Apply Patch in the Patch tab. Use the Update Assistant or Game Assets tab to get your game data — then launch Fortnite!

⚠️

Sideloaded apps expire every 7 days. To re-enable Fortnite: delete the app, reinstall via your sideloader, and re-patch with FnMacAssistant.

Requirements

What you need

FnMacAssistant is designed specifically for Apple Silicon hardware.

Apple Silicon Mac M1, M2, M3, or M4 chip (Intel not supported)
macOS 15.1 or later Sequoia required for full compatibility
Apple ID Required for sideloading via Sideloadly or PlumeImpactor
Sideloadly or PlumeImpactor One sideloading app needed to install the IPA
